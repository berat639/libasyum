# Libasyum Avize

Libasyum Avize kurumsal web sitesi — iç mekânlara değer katan aydınlatma ve avize koleksiyonları.

## Teknolojiler

- **React 18** & **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Leaflet** (Harita ve konum gösterimi)

## Başlangıç

Geliştirme sunucusunu başlatmak için:

```bash
npm install
npm run dev
```

Üretim derlemesi oluşturmak için:

```bash
npm run build
```

Tip kontrolü ve lint çalıştırmak için:

```bash
npm run typecheck
npm run lint
```
